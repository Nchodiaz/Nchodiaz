## How I approach analysis

1. Start with the decision, not the chart.
2. Check provenance, missingness and leakage before modeling.
3. Build a simple baseline before adding complexity.
4. Make the workflow reproducible and the limitations visible.
5. Communicate the result in language the stakeholder can act on.
